## 🔍 Abstract
BhabishyaBot is an AI-driven career guidance system designed to provide personalized career recommendations for students by analyzing their interests, motivations, academic background, and written responses. The system integrates Natural Language Processing (NLP) techniques to evaluate user essays for sentiment, intent, and key themes, while machine learning classification models determine suitable career paths with improved accuracy. The architecture incorporates structured data collection forms, a sentiment-aware essay analyzer, and a classification engine that maps user profiles to potential careers. Additionally, the system generates tailored career roadmaps highlighting essential skills, courses, and development steps. This report presents the overall design, workflow, and system architecture of BhabishyaBot, along with supporting diagrams such as DFDs, UML models, and database structures. The aim is to create an intelligent, scalable, and user-friendly platform that assists students in making informed career decisions.

## 🛠️ Core Research & Technologies
This thesis project bridges software engineering methodology with practical data science and AI applications:

* **Natural Language Processing (NLP):** Utilized for semantic analysis, feature extraction, and sentiment/intent evaluation of student-written career essays.
* **Machine Learning Classification:** Employs trained classification models to map multi-dimensional student profiles into granular career domains.
* **System Design & Modeling:** Structured using rigorous object-oriented analysis, including unified modeling language (UML) architectures, data flow diagrams (DFDs), and structured schema definitions.
